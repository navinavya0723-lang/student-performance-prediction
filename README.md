# Student Performance Prediction System

A Python and Machine Learning mini project that estimates a student's examination score from study-related indicators. The app is built with Streamlit and uses a Random Forest Regressor from scikit-learn.

## Features
- Predicts an estimated score from 0 to 100.
- Displays an indicative performance category.
- Provides general study recommendations.
- Shows a comparison chart.
- Simple interactive web dashboard.

## Inputs
- Study hours per day
- Attendance percentage
- Previous examination marks
- Assignment completion percentage
- Sleep hours per day

## Tech stack
Python, Pandas, NumPy, Scikit-learn, Streamlit, Matplotlib-compatible Streamlit charts, Joblib.

## Setup

Use Python 3.10 or newer.

### 1. Download or clone this repository
```bash
git clone https://github.com/YOUR-USERNAME/student-performance-prediction.git
cd student-performance-prediction
```

### 2. Create and activate a virtual environment (recommended)
Windows:
```bash
python -m venv .venv
.venv\Scripts\activate
```

macOS/Linux:
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies
```bash
python -m pip install -r requirements.txt
```

### 4. Generate the demonstration dataset
```bash
python generate_data.py
```

### 5. Train the model
```bash
python train_model.py
```

The script prints Mean Absolute Error (MAE) and R-squared (R²) on a held-out test set, and saves `student_performance_model.joblib`.

### 6. Run the web app
```bash
streamlit run app.py
```
Open the local URL printed in the terminal (usually http://localhost:8501).

## Machine Learning workflow
1. Generate a reproducible synthetic dataset.
2. Separate input features and target score.
3. Split records into training and test sets.
4. Train a Random Forest Regressor.
5. Evaluate with MAE and R².
6. Save the trained model and load it in the Streamlit app.

## Important limitation
The dataset is synthetic and designed only for demonstrating the machine-learning workflow. The displayed score is an estimate, not a validated prediction of an actual student's result. Real-world use would require an appropriate, consented, representative dataset and careful evaluation.
